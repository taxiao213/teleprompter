# Teleprompter v0.1.0 — 首个公开版本

录口播视频时给你看的提词器 —— **屏幕录制、截图、会议共享都看不到它**。对标芦笋提词器，Windows / macOS / Linux 三平台桌面应用，智能跟读滚动全程离线在本机完成。

### ✨ 功能一览

**录屏隐形**
- 一键开关（`setContentProtection`），录制视频 / 截图 / 会议共享时提词窗彻底消失
- 内置「隐形自检」：一键检测当前机器上提词窗是否真的对采集不可见

**智能跟读**
- 离线语音识别（sherpa-onnx 中英双语流式模型），滚动自动跟随语速
- 停顿即停、回读自动倒退、跳读自动前进；识别不可用时自动回退匀速滚动
- 模型约 200MB（ModelScope 源，国内可达），**识别全程在本机完成，语音不出本机**

**核心提词**
- 透明悬浮窗、置顶、无边框、可拖拽缩放、逐行高亮、匀速滚动
- 文稿导入 Markdown / TXT（可多选），提词窗自动剥离 markdown 语法，上屏为纯口播文本
- 外观调节：字号、速度、行距、字距、文字/背景颜色、不透明度、对齐
- 水平/垂直镜像翻转，适配物理提词器玻璃反射
- 全局快捷键：Space 播放/暂停、↑↓ 调速、R 回到开头（可自定义）
- 点击穿透：鼠标穿透提词窗操作下层应用
- 中英双语界面
